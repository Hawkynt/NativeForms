> The Linux backend for NativeForms: a reflection-free, source-generated P/Invoke layer that renders NativeForms controls through native GTK 3 widgets.

## 📦 Installation

```bash
dotnet add package Hawkynt.NativeForms.Backends.Gtk
```

This is a backend for [NativeForms](https://www.nuget.org/packages/Hawkynt.NativeForms/). Install the core package too — it carries the controls. It compiles on any operating system but needs GTK 3 present at run time.

## ✨ Features

- Renders [NativeForms](https://www.nuget.org/packages/Hawkynt.NativeForms/) controls on Linux through GTK 3.
- The window and the text-bearing primitives are real GTK widgets; every other control is owner-drawn in the platform's visual style.
- Reflection-free and source-generated, so it survives trimming and NativeAOT.
- Referenced but never registered, the whole backend is dropped again by the trimmer.

## 🚀 Quick start

Register the backend before creating a window. Registering more than one is fine: an application can
carry every platform it ships on.

```csharp
using Hawkynt.NativeForms;
using Hawkynt.NativeForms.Backends;
using Hawkynt.NativeForms.Backends.Gtk;

BackendRegistry.Register(new GtkBackend());

var form = new Form { Text = "Hello", Bounds = new(0, 0, 320, 160) };
Application.Run(form);
```
