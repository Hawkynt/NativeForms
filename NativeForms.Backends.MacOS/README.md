> The macOS backend for NativeForms. Published so the backend set is complete and referenceable -- it is not implemented yet, and every entry point throws.

## 📦 Installation

```bash
dotnet add package Hawkynt.NativeForms.Backends.MacOS
```

This is a backend for [NativeForms](https://www.nuget.org/packages/Hawkynt.NativeForms/). Install the core package too — it carries the controls.

## ✨ Features

- Renders [NativeForms](https://www.nuget.org/packages/Hawkynt.NativeForms/) controls on macOS through Cocoa.
- None yet. The type surface exists so consuming code can compile and register against it.
- Reflection-free and source-generated, so it survives trimming and NativeAOT.
- Referenced but never registered, the whole backend is dropped again by the trimmer.

## 🚀 Quick start

Register the backend before creating a window. Registering more than one is fine: an application can
carry every platform it ships on.

```csharp
using Hawkynt.NativeForms;
using Hawkynt.NativeForms.Backends;
using Hawkynt.NativeForms.Backends.MacOS;

BackendRegistry.Register(new CocoaBackend());

var form = new Form { Text = "Hello", Bounds = new(0, 0, 320, 160) };
Application.Run(form);
```

## ⚠️ Limitations
