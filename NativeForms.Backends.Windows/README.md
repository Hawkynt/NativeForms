> The Windows backend for NativeForms: a reflection-free, source-generated P/Invoke layer that renders NativeForms controls through native USER32 window classes.

## 📦 Installation

```bash
dotnet add package Hawkynt.NativeForms.Backends.Windows
```

This is a backend for [NativeForms](https://www.nuget.org/packages/Hawkynt.NativeForms/). Install the core package too — it carries the controls. It compiles on any operating system but only runs on Windows.

## ✨ Features

- Renders [NativeForms](https://www.nuget.org/packages/Hawkynt.NativeForms/) controls on Windows through Win32 / USER32.
- Top-level windows, `BUTTON` and `STATIC` are real USER32 window classes; every other control is owner-drawn.
- Reflection-free and source-generated, so it survives trimming and NativeAOT.
- Referenced but never registered, the whole backend is dropped again by the trimmer.

## 🚀 Quick start

Register the backend before creating a window. Registering more than one is fine: an application can
carry every platform it ships on.

```csharp
using Hawkynt.NativeForms;
using Hawkynt.NativeForms.Backends;
using Hawkynt.NativeForms.Backends.Windows;

BackendRegistry.Register(new Win32Backend());

var form = new Form { Text = "Hello", Bounds = new(0, 0, 320, 160) };
Application.Run(form);
```
